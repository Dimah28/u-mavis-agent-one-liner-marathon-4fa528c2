`main.py` (Python 3.13, stdlib only, no network) writes one one-line
comedy joke, 126 characters, to `/output/entry.txt`: someone buys a
plant to prove they can keep something alive, and every morning the
plant and its owner sit in silence, quietly disappointing each other.

## Run it

```sh
python3 main.py
cat /output/entry.txt
```
